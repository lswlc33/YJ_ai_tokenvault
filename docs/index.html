Get started

四步走完，不到三分钟

从空库到「知道哪把钥匙还能用、还剩下多少钱」，中间没有注册，也没有引导页迷宫。

1

设一个 6 位 PIN

打开应用第一件事。它是解锁与备份的唯一凭证，我们不持有它，也没有找回通道——记牢它，并定期导出备份。

2

录入站点

手动新建，或把站点发来的那段文本整段粘进「粘贴导入」，解析预览后一次建好站点、密钥、模型与账号。

3

点一次探测

首页一个按钮，几秒后就能看到哪些站点通、哪些密钥有效。也支持单独探测某一家或某一把密钥。

4

查余额、做备份

在站点里填好余额查询信息，首页刷新即可看到各站余额；设置 → 同步 → 导出备份，把文件存到网盘或电脑。

没有账号体系，不需要联网激活。应用唯一的出网请求，是你自己点的「探测」「查余额」「检查更新」。

Roadmap

做到哪了

功能层已经落地，剩下的是需要真机、真实额度或特定硬件的验收，以及几个标记为可砍的扩展项。

已落地

  • 数据与加密：Room 数据层、PIN 解锁与自动锁定、密钥与账号密码字段级加密
  • 探测：OpenAI 兼容 / Anthropic / Responses 三协议请求与结果分类
  • 余额：new-api、DeepSeek、OpenRouter、SiliconFlow、Moonshot 适配与自定义 JSON 规则
  • 导入与备份：文本粘贴导入、自包含加密备份包（覆盖 / 合并 / 仅新增）
  • 双端：Android 与 iOS 共用一套 Kotlin Multiplatform 代码，两端备份互通

验收中

  • 探测与余额真机对账：已用真实额度跑通，逐项结果与站点后台核对
  • iOS 真机安装：未签名 IPA 已是完整应用，签名即可装，回归仍在进行
  • 客户端嗅探全链路：被站点拦截时自动换指纹的完整路径

FAQ

常见问题

数据会传到你们的服务器吗？
不会。应用没有账号体系，也不连接我们的任何服务——我们没有服务器。唯一的出网请求是你自己点的「探测」「查余额」「检查更新」，目标是你自己填写的站点地址。
换手机怎么办？
旧手机导出备份文件，新手机安装后选择恢复，输入同样的 6 位 PIN。Android 与 iOS 之间可以互相恢复。
忘了 PIN 怎么办？
PIN 是解开数据的唯一凭证，我们不持有它，也没有找回通道。忘记只能清除应用数据重新录入——所以请务必定期导出备份。
探测会不会花掉我的额度？
常规探测只发最小开销的验证请求，用于确认连通性与密钥有效性，不会跑真实任务。会产生明显花费的逐模型探测，需要你手动单独发起。
支持哪些站点？
不绑定具体商家。只要提供 OpenAI 兼容接口、Anthropic 接口或 Responses 接口的官方或中转站点，都可以自行添加。余额查询内置了 new-api、DeepSeek、OpenRouter、SiliconFlow、Moonshot 的适配规则，其他站点可以自定义 JSON 字段路径。
